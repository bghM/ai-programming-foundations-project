# AI Programming Foundations – Project 1

## Project Description
This project demonstrates a complete, reproducible data workflow using Python.  
The workflow includes data ingestion, cleaning, exploratory data analysis (EDA), visualization, and summary interpretation, forming a foundation for future AI and ML projects.

## What I Built
- `data_workflow.ipynb`
- `requirements.txt`
- `module_summary.pdf`

## Dataset
**Titanic – Machine Learning from Disaster (Kaggle)**  
https://www.kaggle.com/c/titanic/data

## How to Run the Project

### 1. Clone the repository
```bash
git clone https://github.com/bghM/ai-programming-foundations-project.git
cd ai-programming-foundations-project
pip install -r requirements.txt
jupyter notebook data_workflow.ipynb
```

### 2. Reproducibility
	•	All dependencies are pinned in requirements.txt
	•	The notebook runs top-to-bottom without errors
	•	Git was used with multiple commits and branches (dev, main)
